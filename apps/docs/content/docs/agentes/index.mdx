## Patrones comunes

- **Una sola puerta al LLM.** Todo pasa por `LLMClient.structured(prompt, Schema, system=..., default=...)`. La salida se valida con Pydantic; si no valida, se reintenta y luego se usa `default`. Ningún agente se cae por el LLM. Ver [LLM client](/docs/llm-client).
- **Catálogos deterministas.** Los nombres que propone el LLM se normalizan en código (`graph/taxonomy.py`): coincidencia exacta de etiqueta o alias y luego similitud difusa (`difflib`, umbral 0,82 para habilidades y 0,85 para corregimientos). Lo que no alcanza el umbral se descarta: nunca se inventan habilidades.
- **Evidencia literal.** `evidence_in` exige que la evidencia sea un fragmento literal del texto fuente (sin acentos, mayúsculas ni signos).
- **Guardrails antes del LLM.** Mercado y Perfil pasan el texto libre por `screen_input` (`graph/guardrail_port.py`). Ver [Solvers y guardrails](/docs/solvers-guardrails#guardrails).
- **Traza siempre.** Cada nodo abre `with traced(session, thread_id, "<agente>", llm) as trace:` y rellena `tool`, `input_summary`, `decision`, `reason` y `output_summary`.
- **Prompts** en `llm/prompts.py` (`MERCADO_*`, `PERFIL_CV_*`, `PERFIL_INTERVIEW_*`, `POSTULACION_*`, `FORMACION_*`).
